## 要求
请从以下维度进行设计，输出 Markdown 格式：
1. **系统架构图** - 用 ASCII 艺术或文字描述系统架构层次
2. **技术方案** - 推荐的技术栈（前端、后端、数据库、部署等）及选型理由
3. **模块划分** - 系统的主要功能模块及其职责
4. **模块关系** - 各模块之间的依赖与交互关系
5. **数据库设计建议** - 核心数据表设计建议（表名、主要字段说明）
6. **API 设计建议** - 主要 RESTful API 端点设计建议
7. **安全设计** - 认证、授权、数据安全方面的建议

## 输出格式
请使用 Markdown 语法，结构清晰，每个部分以 ## 开头。
